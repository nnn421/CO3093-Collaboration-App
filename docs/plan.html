Distributed & Streaming-based Collaboration Application

Hệ thống cộng tác mạng thời gian thực trên nền socket thô (Python Raw Sockets & asyncio). Phân tách chặt chẽ kênh điều khiển TCP và kênh truyền luồng UDP tin cậy đa luồng, hỗ trợ mã hóa dữ liệu AES-256-GCM.

Tiến độ: 4 Giai đoạn kỹ thuật Hình thức: Nhóm 3 người Ngôn ngữ: Python 3.10+ Ràng buộc: Raw Socket only Thang điểm: 10.0

Phân định Trách nhiệm Nhóm — 3 tầng kỹ thuật độc lập tương ứng 3 thành viên
Người A
Tầng Giao thức Truyền tải (Transport)
Xây dựng lõi truyền tải tin cậy qua UDP: Stop-and-Wait, Cửa sổ trượt (Sliding Window), Selective Repeat, SACK trong payload, RTO động, Đa luồng (Multi-streaming) khử nghẽn HoL và Kiểm soát tắc nghẽn (Reno/CUBIC).
UDP Datagram Sliding Window Multi-stream Congestion Control
Người B
Tầng Máy chủ và Bảo mật (Server Core)
Xây dựng máy chủ asyncio trung tâm: Bắt tay đăng nhập TCP, băm mật khẩu PBKDF2, User Registry phát hiện Heartbeat, định tuyến Broadcast/DM, File Relay có back-pressure và mã hóa AES-256-GCM với khóa X25519/HKDF.
asyncio Server PBKDF2 Auth X25519 + AES-GCM Message Router
Người C
Tầng Máy khách, Giao diện & Kiểm thử
Xây dựng cấu trúc gói tin (packet.py), bộ suy hao mạng (lossy.py), ClientAgent, Web Server mini bằng raw socket HTTP/1.1, giao diện Web UI hiển thị tiến trình file, module truyền file SHA-256 và bộ test tự động pytest.
Raw HTTP Server Web UI (Vanilla JS) Lossy Simulator pytest suite
